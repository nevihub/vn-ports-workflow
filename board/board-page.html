How to read this

All ports shows every game at a glance. Pick a game for its Big picture (the stages from start to finish, where it stands, what happened when) or its Tickets (every piece of work, who is on it).

    • Big picture % - worked out from the tickets: each stage counts finished tickets (and the share an agent reports on the one in progress), weighted by how big the stage is. An estimate, never typed in by hand.
    • Not started - nobody has picked it up yet · In progress - someone is on it now · Stuck - needs a decision · Done - finished, newest first
    • no update for Xh - an in-progress card whose agent has gone quiet

    The colored tags name AI models: a card says which one should run it (and at which effort level), a backup, and a third pick for when the Codex and Claude subscriptions are both out; while an agent works, its model shows on the card instead.

    • Sol 6.1 · max hardest work - best at long agent runs for the money
    • Opus 5.5 · medium hardest work, backup - medium default (FrC 57.1); max burns limits fast
    • GLM-5.3-Flash everyday + verify work - free, honest, no effort tiers
    • DeepSeek V4.1 Flash long-context reading - fast, but guesses when unsure; one fixed model in OpenCode
    • Haiku 5.5 · max small, checkable jobs - cheapest capable
    • Luna 6 tiny/short jobs only - cheap, weak at long runs

    Third picks ride OpenCode Go (active since 2026-10-18) - the same key works inside the Claude Code and Codex clients, so a drained subscription is a model swap, not a workflow change:

    • Muse Spark 1.3 Go volume workhorse - 226.6k req/mo, GPQA 93.5
    • Gemini 4 Argon Go reserve for one critical run - VN 62.4, honesty 85; ~2.1k req/mo burns fast
    • GLM-5.3 Go honest hard tickets - TB4 41.9; 1,080 req/mo
    • MiMo-V2.6-Pro Go hard-work fallback + coding volume - TB4 34.8; 16.3k req/mo
    • Step 5 Go long reads + crash digging - LCR 88.3, ITBench 55.6
    • Kimi K3 Go giant-context reads - LCR 88.7 leader; 490 req/mo
    • MiniMax M3 Go specs/docs + verify reading - honesty 81.6, IFB 82.9
    • Kimi K2.7 Code Go repo/coding - 6.75k req/mo; no AA row yet
    • Go models are one fixed variant each in OpenCode (opencode-go/muse-spark-1.3-contributor, ...) - the effort names in the charts are AA's tier labels, not selectors.
